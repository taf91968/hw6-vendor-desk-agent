5Recommendation to the store manager

Should Campus Customs turn this agent on for real vendor mail?

✓ Recommendation: yes, turn it on for real vendor mail, as a reviewer, not a buyer. It drafts the recommendation; a person still approves every order, email, and payment.
  • What it costs: $3.75 a month for 30,000 documents (1,000 a day), measured on the exam run with all defenses and prompt caching on ($0.000125 per document). Without caching it would be about $12.61 a month. That is less than one hour of staff time a month.
  • Why yes: it got all 12 practice documents right in every setting, gave sensible answers on the 10 exam documents, and never sent an email or approved a payment. Those tools are locked behind a human sign-off. With all defenses on it is also cheaper than without them, because code (not the model) makes the decision.
  • Why not alone: it can still be fooled. One exam document hid a fake "vendor of record" and fooled one run before the code layer was tightened. One red-team email shows a person one quote and the agent another, and it still fools the defended agent. Until the reader compares both versions of an email, a person should check every email the agent recommends.
  • Before go-live: (1) flag emails whose plain-text and HTML versions disagree, and strip invisible text from PDFs; (2) keep the Portkey response cache off for this agent; (3) have the buyer spot-check 1 in 10 decisions for the first month.
